# Intelligent Systems Coursework

The projects cover genetic algorithms, neural networks, computer vision, transfer learning, and fuzzy logic control.

## Projects

| # | Project | Topic | Technologies |
|---|---|---|---|
| 1 | [Genetic Algorithm Penalty Methods](lazareske4/) | Constrained optimization using genetic algorithms | Python, NumPy |
| 2 | [Route Optimization](UMINT_cv02/) | Genetic algorithm for route optimization | Python, NumPy, Matplotlib |
| 3 | [TSP Mutation Strategies](UMINT_cv03/) | Comparing mutation strategies for the Traveling Salesman Problem | Python, NumPy, Matplotlib |
| 4 | [Investment Optimization](UMINT_cv04/) | Constrained investment optimization with genetic algorithms | Python, NumPy, Matplotlib |
| 5 | [CTG Neural Network Experiments](UMINT_cv05/) | Classification experiments using cardiotocography data | Python, PyTorch, pandas |
| 6 | [CTG Classification with MLP](UMINT_cv06/) | Multilayer perceptron models for CTG classification | Python, PyTorch, pandas |
| 7 | [MNIST Neural Network Comparison](UMINT_cv07/) | MLP and CNN models for handwritten digit recognition | Python, PyTorch, TorchVision |
| 8 | [Food-101 Image Classification](UMINT_cv08/) | Transfer learning with AlexNet, ResNet18, and MobileNetV2 | Python, PyTorch, TorchVision |
| 9 | [Crossroad Traffic Control](UMINT_cv09/) | Fixed-time and Sugeno fuzzy traffic-light controllers | Python, Fuzzy Logic |

## Technologies

- Python
- NumPy and pandas
- Matplotlib
- PyTorch and TorchVision
- Genetic algorithms
- Multilayer perceptrons and convolutional neural networks
- Transfer learning
- Fuzzy logic control
